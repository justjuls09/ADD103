1. Understanding Git and GitHub

Git is a version control system that helps track changes made to files and projects. It allows developers to save different versions of their work, review changes, and restore previous versions if needed.

GitHub is an online platform that hosts Git repositories in the cloud. It makes it easy to store projects online, collaborate with others, and back up code. Git works on a local computer, while GitHub provides a remote location where Git repositories can be shared and managed.

Git and GitHub work together because Git tracks and manages changes, while GitHub stores those changes online. Using both tools helps keep projects organized and makes collaboration easier.

2. VS Code Source Control Process

To save my work using Source Control in VS Code, I first make changes to my files and save them. I then open the Source Control panel and review the modified files listed under Changes.

Next, I stage the files I want to include in the commit by clicking the plus sign next to the files or by using the option to stage all changes. After staging, I enter a commit message that describes what changes were made.

I click Commit to save the changes to the local Git repository. Finally, I use Push or Sync Changes to upload the commit to GitHub so the online repository stays up to date.
